# LD Express website

Static source for the public GitHub Pages status site at
<https://lordof2l.github.io/ld-express/>.

The site intentionally has no JavaScript, forms, cookies, analytics, external
fonts, or third-party embeds. A restrictive Content Security Policy blocks
scripts, network requests, frames, objects, media, and form submissions. Search
indexing is disabled. Current public content states that LD Express is inactive
and is not accepting work.
